# JangaFX 近距离性能审计（2026-11-06）

## 早期单 brick 混合光照实验（2026-11-26）

RTX 3070，StablePowerState 开启，2560×1440，半分辨率烟雾，Sponza 相机 10，JangaFX Q4 第 80 帧暂停，extinction 6/m。开启烘焙 AO，三线性密度过滤，步长设置 2.5 cm 并启用 Double brick ray step（实际还受体素间距限制）。每种配置随机交错跑 3 轮，每轮 150 帧。表中为每轮 GPU `volume_accumulation_ms` 中位数再取中位数，三轮间最大跨度 0.0021 ms。

| 单 brick 光照策略 | GPU ms |
|---|---:|
| 纯逐步 | 1.630 |
| 混合，阈值 0 | 1.729 |
| 混合，阈值 0.25 | 1.620 |
| 混合，阈值 0.65 | 1.415 |
| 混合，阈值 1 | 1.053 |
| 纯角点 | 1.029 |

混合 VS 总会计算角点光照，PS 依据相机 T-LUT 的最大 RGB 分量选分支。阈值 0 对正 T 全走逐步，耗时比纯逐步多 0.098 ms。阈值 1 全走角点，比纯角点多 0.024 ms。此计时包含 draw 的 VS、PS 与输出开销。混合 shader 已由下文的 GPU 分类取代。此处的角点是八角光照插值，现有 per-brick 质心模式有独立的实现与成本。

### 单 brick PS 随机密度过滤

同一镜头与采样设置，修正 spotlight 表面阴影淡出后，每个配置正反顺序各跑一轮，每轮 150 帧。下表是两轮帧中位数的平均值，单位 ms。

| 光照策略 | Q4 三线性 | Q4 随机单 tap | 变化 |
|---|---:|---:|---:|
| 纯逐步 | 1.630 | 1.491 | −8.5% |
| 纯角点 | 1.027 | 0.988 | −3.8% |
| 混合，阈值 0.65 | 1.416 | 1.481 | +4.6% |

随机版只改变 accumulation 的密度重建。纯逐步场景的最终 8-bit RGB 单帧相对三线性的逐通道 RMS 误差为 1.22/255。该比较只覆盖固定相机、固定资产帧。

### Brick 几何 A/B（2026-11-26）

两边都用 Q4 三线性、indexed draw、相同步长和采样相位。角点模式在首顶点计算光照，再用普通 flat varying 传递。RTX 3070、2560×1440，固定第 80 帧，每项记录 100 帧中位数。每个单元格为“矩形 / 六面体”，单位 ms。半分辨率取 `volume_accumulation_ms`，全分辨率取 `accumulation_ms`。

| 镜头 | 纯逐步 | 纯角点 | 混合 T=0.65 |
|---|---:|---:|---:|
| 常规距离，相机 0，半分辨率 | 0.537 / 0.628 | 0.383 / 0.651 | 0.582 / 0.803 |
| 近景，相机 10，半分辨率 | 1.629 / 1.713 | 1.101 / 1.267 | 1.672 / 1.797 |
| 烟内，相机 11，半分辨率 | 4.124 / 4.070 | 2.742 / 2.839 | 3.825 / 3.800 |
| 近景，相机 10，全分辨率 | 5.604 / 5.619 | 3.625 / 3.722 | 5.392 / 5.346 |

矩形每块两三角形，PS 求射线与盒子的入口和出口。六面体每块八个索引顶点、十二个三角形并开启硬件背面剔除，用光栅化表面的深度恢复入口，解析计算出口。跨近裁面时反转绕序，取出口并恢复入口。逐像素比较的 12 对截图最大单通道差 5/255。根据上述测量保留矩形路径。前一节的混合光照数据包含当时的分布式角点实现，本表代表目标硬件可用的角点路径。

### GPU 分类后的矩形与六面体（2026-11-27）

在 JangaFX 场景的 **VDB pixel march** 中选 **Classified / rectangle** 或 **Classified / six faces**。
两种代理共用 **Brick LOD**，可在运行时切换 Balanced（默认）和 Performance。
命令行 `--vdb-brick-lod balanced|performance` 选择分类矩形，附加 `--vdb-brick-classify-cube` 选择六面体。

分类 CS 在每个非空可见 brick 中心的屏幕 UV、包围盒最前方深度查一次 T-LUT，取 RGB 的最大分量 T。
跨近裁面的 brick 直接用逐步光照。其余 brick 按下表处理。

| 条件 | 工作 |
|---|---|
| T = 0 | 剔除，跳过绘制 |
| 0 < T ≤ 分界值 | 低档：brick 中心光照，沿裁剪后的像素射线段取一个中点样本 |
| T > 分界值 | 高档：沿射线逐步采样密度、T 和光照 |

Balanced 分界值为 0.50，Performance 为 0.70。每个 actor 仍提交两个 indexed indirect draw，
各绑定独立的像素 shader。低档 shader 直接积分一次，不带多步循环。
BackN 按玻璃后方的实际长度累积。精确零剔除是整块近似，brick 投影边缘可能比中心更透光。
两个实例列表从同一缓存两端写入。128³ 体数据按 4³ 分块时，共用 512 KiB 实例缓存和 40 B draw args。

矩形 PS 用 slab 求交。六面体提交 8 个索引顶点、12 个三角形，开启背面剔除。
光栅面提供一个端点，PS 只求对侧端点。跨近裁面的砖块在 CS 标记一次，VS 改画出口；
全分辨率入口面参与硬件深度测试，出口面按近裁深度测试，在 PS 内用真实面深度与场景深度截断。

#### 两档与原三档对照

RTX 3070，StablePowerState，2560×1440，半分辨率矩形，第 80 帧暂停，关闭 TAA。每项取 100 帧 accumulation GPU 中位数（ms），不含 upsample。原三档 Balanced 在 0.25 < T ≤ 0.85 的区域用中心光照、多步密度；两档把这个区间按单一分界值划给高档或低档。

| 镜头 | 原三档 Balanced | 两档 Balanced | 两档 Performance |
|---|---:|---:|---:|
| 普通近景，6/m | 1.094 | 1.269 | 1.142 |
| 浓烟穿玻璃，32/m | 0.839 | 0.910 | 0.866 |
| 烟内，32/m | 1.672 | 2.050 | 1.950 |

普通近景对纯逐步参考的整帧 RGB RMS 依次为 2.07、1.32、1.79（8-bit 色阶）。
把所有原中间档都降为 1-step（分界 0.85）时为 1.046 ms、RMS 2.40。
开启 TAA 后，同一普通近景的 accumulation 加 upsample 中位数为 1.629 ms（Balanced）和 1.499 ms（Performance），Performance 的 P95 为 1.508 ms。计时范围只包含这两段 GPU 工作。以上为固定镜头结果。

## 判断

首要瓶颈是大量 ray steps 中的双帧密度读取、手工 trilinear 解码、T-LUT 查询与控制流。
参考路径每步四次密度；每次双帧各解码八个 voxel，最多 64 个 voxel 值，不等于 64 次 DRAM 事务。
跳空保留；它当前跳过密度/光照但仍迭代原步进格点并查询 T-LUT。
仅降阴影质量收益有限。随机四 tap 升采样存在大量独立寻址、导向深度和四张 MRT 的点加载。

首选实验：每帧解码并预插值到一张 128³ R16F（4 MiB）纹理，统一供 splat、raymarch、MSM 使用。
让 GPU 硬件做空间插值；时间插值在线性密度域完成，避免逐像素重复双帧解码。
新增构建 pass 与资源状态转换必须一起计时，不能将其开销移出预算。
其次比较固定或 coherent 四 tap 重建，保持 TAA 并做运动验收；再评估 5–10 cm 的步长。
仍不足时再考虑更低分辨率，但不保证视觉无损。

本轮是固定半帧测试，包含双帧采样，不含每帧切换时完整资产上传成本。
当前实现跨帧会重传两个 brick 帧；后续应保留上一帧，仅上传新帧，并单独测动态播放。
测试只验证静态画面与耗时，不能据此认定放大步长或换重建核后仍保持认可的动态质量。
1.5 ms 若包含全部烟雾增量，必须另做无烟基线；本轮共享 pass 耗时不能直接当增量相加。
